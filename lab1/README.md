# Первая лаба

Вариант 6 — пирамида. C++ и Vulkan, на основе [шаблона преподавателя](https://github.com/vladeemerr/vulkan-starter-app).

Можно менять проекцию, положение, поворот и масштаб пирамиды.

## Запуск на macOS

Нужны Vulkan SDK 1.4.321.0 в `~/VulkanSDK/1.4.321.0`, CMake и инструменты компилятора Apple. При первой сборке нужен интернет для загрузки библиотек.

Открыть `run-macos.command` двойным щелчком или выполнить из папки `lab1`:

```sh
./run-macos.command
```

После изменения кода:

```sh
./run-macos.command --build
```

Основной код — в `source/`, шейдеры — в `shaders/`.
